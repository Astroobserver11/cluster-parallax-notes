# GALEX and Globular Clusters
Date: 2026-10-25

## Resolution Limits
- GALEX is UV-only (far UV + near UV)
- Point-spread function: ~4.2 arcsec FUV, ~5 arcsec NUV
- Too coarse to resolve individual stars in any globular cluster core
  - M4 core is under 1 arcsec
  - Even the loosest cluster cores exceed GALEX's PSF

## What GALEX Can Do
- Photometry of bright UV outliers in cluster outskirts where crowding eases
- Blue stragglers are genuinely NUV-bright
- Cross-match GALEX catalog with HST positions for UV excess flags on BS candidates
- No need to resolve stars directly for this approach

## Published Work
- GALEX study of M13 and a handful of other clusters
- Used GALEX UV photometry for horizontal-branch and BS selection
- Approach: UV excess as a membership/selection flag, not spatial resolution

## Relevance to BS Soft X-ray Experiment
- GALEX NUV flags can pre-select BS candidates before eROSITA cross-matching
- Reduces false positives in the soft X-ray stacking analysis
- Useful for clusters without complete HST UV Legacy Survey coverage
- Combine: GALEX NUV excess + eROSITA soft counts + Gaia PM membership = triple filter

## Key Limitation
- Cannot study core dynamics or radial BS distributions inside ~1-2 core radii
- For core work, HST UV Legacy Survey (Piotto et al.) remains the standard
- GALEX is a wide-field complement, not a replacement
